# 數學冒險王

繁體中文、支援國小三年級與五年級上學期複習的互動數學遊戲。React + TypeScript + Vite + Three.js；3D 首頁搭配 CSS／SVG 教具，無後端、無登入、無付費 API。

## 啟動

需要 Node.js 20.19+。

```sh
npm install
npm run dev
```

開啟終端顯示的網址。iPad 與電腦在相同區域網路時，可使用終端顯示的 Network 網址；可能需要允許本機防火牆連線。

```sh
npm test
npm run build
```

`dist/` 可部署到靜態網站主機。字型提供系統字型 fallback；Google Fonts 無法連線時遊戲仍可操作。

## 功能

- T01–T20 全部題型、六個冒險關卡、自由練習、錯題挑戰、20 題模擬測驗、家長報告。
- 錢幣與積木教具、數線、數字卡；排序採可觸控與鍵盤操作的兩卡交換。
- 兩層提示、首次答錯引導、第二次答錯解說、完成訂正後可選同類型新題。
- 獨立答對 10 星、提示後答對 5 星、訂正後答對 3 星。過關須至少 80% 獨立答對。每 5 題可略過鼓勵動畫，尊重減少動態效果設定。
- 每題完成即儲存紀錄；答錯即收錄錯題。重新整理後保留報告、星星、關卡與錯題；未完成回合不續接。
- 依能力連續 3 題首次獨立答對升級、連續 2 題首次答錯降級；家長可鎖定難度。改善中／熟練要求不同題目連續 2／3 次獨立答對。
- 各題型次數、獨立答對率、平均嘗試、提示率、最近時間、熟練度、前三弱項練習、CSV 匯出、兩次確認重設。
- localStorage 使用版本化 `math-adventure-progress-v1`，毀損資料安全回復；儲存失敗顯示提醒。資料只在目前裝置與瀏覽器。
- 一般數量題暖身限制在 1000 以內；明確教授四位數、一萬、換鈔與組數的題型保留該能力必要的數值範圍。挑戰級維持三年級四位數範圍；條件組數仍使用完整排列驗證。

## 題庫與測試

`src/questions.ts`：純函式出題、排列演算法、輸入正規化與驗證。`Question` 包含答案、提示、逐步解說；T18 明確要求任選一個，驗證全部合法解。新增題型時擴充 `topics` 與 `generate` 的分支並加入測試；每回合以題目及教具資料組成的 ID 排除重複。

`src/progress.ts`：資料儲存格式、學習統計、連續練習與難度。

`src/main.tsx`：頁面、答題狀態與回饋流程。`src/style.css`：響應式介面。

測試包含每題型三個固定種子案例、每類 20 種不重複變化、1,200 題跨難度生成測試，以及數字格式、多解、零位值與進度測試。測試使用獨立計算驗證生成器答案。

## 探險豐富內容（2026-10-22）

- 每日 3 項任務：完成 5 題、探索 3 種題型、完成 10 題。訂正完成也計入，每項完成可領 20 顆星星，每天各限一次，以裝置當地日期更新。
- 探險收藏：8 枚成就徽章，包含首次練習、探索題型、訂正與關卡完成。結算頁會顯示本回合新獲得的徽章。
- 星星商店：6 位夥伴，森林小狐免費，其他夥伴可用 50–300 顆星星解鎖。解鎖後可免費切換，首頁與答題頁會顯示目前夥伴。
- 每個關卡都有開場小故事與完成回饋，鼓勵慢慢想，不加入時間壓力。
- 頁首顯示「可用星星」（答題星星 + 已領取任務獎勵 − 已解鎖夥伴費用）；首頁統計保留「累積答題星星」。
- 新收藏以選填 `rewards` 欄位保存在原本進度內，舊存檔可直接沿用。重設學習資料時也會清除收藏與每日獎勵。
- `src/rewards.ts` 管理任務、扣款、夥伴與徽章；`src/Adventure.tsx` 提供相關介面。新增 8 項測試，涵蓋重複領取、跨日、餘額不足、重複購買、舊資料相容與重新載入。

## 3D 探險島入口

- 首頁使用 Three.js 即時繪製六座立體浮空島，分別有燈塔、森林、列車、商店、城堡與獎盃；所有模型均由程式幾何建模，不需下載模型或圖片。
- 點選島嶼或下方關卡按鈕，確認後按「出發探險」開始原本的題型回合。已通過的關卡顯示不同顏色的編號標記。
- 左右拖曳／滑動可小幅旋轉，也可使用旋轉按鈕；觸控保留垂直捲動。小螢幕改為兩欄三排島嶼。
- 可暫停漂浮；尊重系統減少動態效果設定，離開畫面或切換分頁時停止動畫。離開首頁會釋放模型、材質、貼圖、事件與 WebGL 資源。
- 3D 引擎按需載入；若裝置不支援 WebGL 或繪圖環境失效，保留一般關卡選擇與出發按鈕，仍可玩所有題型。
- 實作：`src/IslandEntrance.tsx`（入口與替代介面）、`src/islandScene.ts`（場景與互動）、`src/island.css`（版面）。
- 驗證：92 項既有邏輯測試與 TypeScript／正式建置通過；3D 視覺、光線、點選與 iPad 手勢尚未經實機瀏覽器驗證。Three.js 動態載入檔案約 136 KB gzip；建置仍會提示其原始壓縮大小超過 500 KB。

## 線上遊玩與自動部署

遊戲網址：https://weilitien.github.io/math-adventure/

推送到 `main` 後，GitHub Actions 會安裝依賴、執行全部測試、建置，再部署到 GitHub Pages。部署進度可在儲存庫的 Actions 頁面查看；測試或建置失敗時不會覆蓋線上版本。

`vite.config.ts` 將正式建置的資源路徑設為 `/math-adventure/`，本機開發仍使用 `/`。若更改儲存庫名稱或改用其他網址部署，需同步調整 `base`。線上進度儲存在各裝置的瀏覽器，本機開發站的紀錄不會自動轉移到線上站。

## 五年級上學期複習專區（2026-10-29）

直接入口：https://weilitien.github.io/math-adventure/?grade=5

頁首可切換三年級／五年級。年級選擇會記住，`?grade=3` 或 `?grade=5` 可指定開啟的專區。

### 課程範圍與來源

使用者指定康軒版、五上第一次期中考，但尚未確認學校範圍。此專區預設勾選下列前四單元，第五單元為選讀，**不表示學校考試必定涵蓋這些單元**：

1. 多位小數與加減：位值、大小比較、加減、取概數、生活問題。
2. 因數與公因數：所有因數、最大公因數、平均分裝。
3. 倍數與公倍數：正倍數、2／5／10 倍數判別、最小公倍數、週期問題。
4. 擴分、約分與通分：擴分、最簡分數、異分母比較、通分、分數表示除法。
5. 多邊形與扇形（可加選）：頂點、三角形邊長、三角形／四邊形內角、扇形圓心角。

依[康軒 114 學年公開課程架構](https://945cloud.knsh.com.tw/E/promo/Show/upload/material/3/114%281%29高年級綜合文宣.pdf)整理，尚未取得孩子的 115 學年課本與考試公告，請以實際教材為準。題目均自行生成，非康軒官方題庫，不複製課本習題。

### 功能與驗證

- 23 種生成題型、5 個單元與混合挑戰，沿用 3D 島嶼入口。未勾選的單元無法從入口開始，混合挑戰只出已勾選範圍，輪流抽取各單元題型。
- 每單元 10 題、混合 20 題；至少 80% 首次獨立答對獲得過關標記。兩層提示、兩次答錯後逐步解說、完成訂正後繼續。
- 小數採整數縮放計算，輸入以 BigInt 有理數精確比較，接受全形數字與小數末尾 0。分數接受等值寫法，但「最簡分數」會驗證互質；所有因數要求完整且不重複，順序不限。
- 提供等長分數長條、位值提示、幾何示意、扇形 SVG。幾何題註明圖形不按比例，按題目角度計算。
- 五年級有獨立星星、錯題、過關與學習報告／CSV；錯題與弱項練習遵守所選範圍。五年級暫未加入三年級的每日任務與夥伴商店。
- 儲存鍵為 `math-adventure-grade5-progress-v1`，與三年級資料隔離。切換年級或重設五年級不會清除三年級紀錄。未完成回合不續接。
- `src/grade5/questions.ts`：出題與驗證；`progress.ts`：獨立紀錄；`App.tsx`、`Visual.tsx`、`style.css`：頁面與教具。
- 新增 122 項測試，包括每型 3 個固定種子案例、每型 100 題獨立驗算（共 2,300 題）、每型 20 題不重複、31 種非空範圍組合、進位邊界、分數與因數格式、存檔與年級隔離。全專案 214 項測試通過，正式建置通過；未執行實機瀏覽器／iPad 操作驗證。

### 範圍與內容來源

沿用上學期方向。前兩單元已對照[康軒 115 上學期數位服務](https://digitalmaster.knsh.com.tw/el/nature/digital1-midterm/index.html)的單元一「多采多姿的植物」、單元二「生活中的力」。預設只勾選這兩個單元，不代表學校實際考試範圍。

另提供「奇妙的空氣」、「廚房裡的科學」加選，參考[康軒 114 學年自然課程架構](https://945cloud.knsh.com.tw/e/promo/show/upload/material/4/114%281%29自然領域文宣.pdf)，後兩單元尚待與孩子的 115 學年課本核對。

- 全部 48 題為自行編寫，每單元 12 題，非出版社官方題庫。包含單選、多選、步驟排序，不搬用課本題目或圖片。
- 單元闖關抽 10 題；綜合挑戰輪流從所選單元抽最多 20 題。一回合不重複，同一回合數量不足時採實際題數（例如只選一單元，混合挑戰為 12 題）。不將選項洗牌算成新的題目。
- 兩層提示、第二次答錯後顯示解說、完成訂正後繼續。獨立答對 10 星、提示後答對 5 星、訂正 3 星。獨立答對至少 80% 可過關。
- 支援排序的上移／下移按鈕，可用觸控或鍵盤操作；多選要求選齊正確答案且不得多選。
- 小實驗室提供植物構造觀察、磁極預測與吸斥示意、氣球空氣量示意、少量材料在足量水中的溶解觀察。活動依所選單元顯示，不計入答題分數，亦不列入過關數量。圖形是概念示意，並非定量物理模擬。
- 獨立的星星、錯題、學習報告與 CSV 匯出。自然存檔鍵為 `math-adventure-science3-progress-v1`，不覆蓋三／五年級數學資料；重設只影響自然紀錄。尚未新增自然專用商店或每日任務。
- `src/science3/questions.ts`：題庫與多選／排序驗證；`progress.ts`：存檔與統計；`App.tsx`、`Lab.tsx`、`style.css`：介面與示意活動；`src/courseSelection.ts`：相容舊連結的科目選擇。
- 新增 70 項測試：48 題答案／選項與洗牌檢查、多選各種組合、15 種單元範圍各 20 回合、磁極四種組合、儲存與資料隔離、舊數學連結相容性。全專案 284 項測試通過，TypeScript 與正式建置通過。尚未執行實機瀏覽器或 iPad 手勢驗證。
