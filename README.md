# 數學冒險王

繁體中文、適合國小三年級的互動數學遊戲。React + TypeScript + Vite + Three.js；3D 首頁搭配 CSS／SVG 教具，無後端、無登入、無付費 API。

## 啟動

需要 Node.js 20.19+。

```sh
npm install
npm run dev
```

開啟終端顯示的網址。iPad 與電腦在相同區域網路時，可使用終端顯示的 Network 網址；可能需要允許本機防火牆連線。

```sh
npm test
npm run build
```

`dist/` 可部署到靜態網站主機。字型提供系統字型 fallback；Google Fonts 無法連線時遊戲仍可操作。

## 功能

- T01–T20 全部題型、六個冒險關卡、自由練習、錯題挑戰、20 題模擬測驗、家長報告。
- 錢幣與積木教具、數線、數字卡；排序採可觸控與鍵盤操作的兩卡交換。
- 兩層提示、首次答錯引導、第二次答錯解說、完成訂正後可選同類型新題。
- 獨立答對 10 星、提示後答對 5 星、訂正後答對 3 星。過關須至少 80% 獨立答對。每 5 題可略過鼓勵動畫，尊重減少動態效果設定。
- 每題完成即儲存紀錄；答錯即收錄錯題。重新整理後保留報告、星星、關卡與錯題；未完成回合不續接。
- 依能力連續 3 題首次獨立答對升級、連續 2 題首次答錯降級；家長可鎖定難度。改善中／熟練要求不同題目連續 2／3 次獨立答對。
- 各題型次數、獨立答對率、平均嘗試、提示率、最近時間、熟練度、前三弱項練習、CSV 匯出、兩次確認重設。
- localStorage 使用版本化 `math-adventure-progress-v1`，毀損資料安全回復；儲存失敗顯示提醒。資料只在目前裝置與瀏覽器。
- 一般數量題暖身限制在 1000 以內；明確教授四位數、一萬、換鈔與組數的題型保留該能力必要的數值範圍。挑戰級維持三年級四位數範圍；條件組數仍使用完整排列驗證。

## 題庫與測試

`src/questions.ts`：純函式出題、排列演算法、輸入正規化與驗證。`Question` 包含答案、提示、逐步解說；T18 明確要求任選一個，驗證全部合法解。新增題型時擴充 `topics` 與 `generate` 的分支並加入測試；每回合以題目及教具資料組成的 ID 排除重複。

`src/progress.ts`：資料儲存格式、學習統計、連續練習與難度。

`src/main.tsx`：頁面、答題狀態與回饋流程。`src/style.css`：響應式介面。

測試包含每題型三個固定種子案例、每類 20 種不重複變化、1,200 題跨難度生成測試，以及數字格式、多解、零位值與進度測試。測試使用獨立計算驗證生成器答案。

## 探險豐富內容（2026-10-22）

- 每日 3 項任務：完成 5 題、探索 3 種題型、完成 10 題。訂正完成也計入，每項完成可領 20 顆星星，每天各限一次，以裝置當地日期更新。
- 探險收藏：8 枚成就徽章，包含首次練習、探索題型、訂正與關卡完成。結算頁會顯示本回合新獲得的徽章。
- 星星商店：6 位夥伴，森林小狐免費，其他夥伴可用 50–300 顆星星解鎖。解鎖後可免費切換，首頁與答題頁會顯示目前夥伴。
- 每個關卡都有開場小故事與完成回饋，鼓勵慢慢想，不加入時間壓力。
- 頁首顯示「可用星星」（答題星星 + 已領取任務獎勵 − 已解鎖夥伴費用）；首頁統計保留「累積答題星星」。
- 新收藏以選填 `rewards` 欄位保存在原本進度內，舊存檔可直接沿用。重設學習資料時也會清除收藏與每日獎勵。
- `src/rewards.ts` 管理任務、扣款、夥伴與徽章；`src/Adventure.tsx` 提供相關介面。新增 8 項測試，涵蓋重複領取、跨日、餘額不足、重複購買、舊資料相容與重新載入。

## 3D 探險島入口

- 首頁使用 Three.js 即時繪製六座立體浮空島，分別有燈塔、森林、列車、商店、城堡與獎盃；所有模型均由程式幾何建模，不需下載模型或圖片。
- 點選島嶼或下方關卡按鈕，確認後按「出發探險」開始原本的題型回合。已通過的關卡顯示不同顏色的編號標記。
- 左右拖曳／滑動可小幅旋轉，也可使用旋轉按鈕；觸控保留垂直捲動。小螢幕改為兩欄三排島嶼。
- 可暫停漂浮；尊重系統減少動態效果設定，離開畫面或切換分頁時停止動畫。離開首頁會釋放模型、材質、貼圖、事件與 WebGL 資源。
- 3D 引擎按需載入；若裝置不支援 WebGL 或繪圖環境失效，保留一般關卡選擇與出發按鈕，仍可玩所有題型。
- 實作：`src/IslandEntrance.tsx`（入口與替代介面）、`src/islandScene.ts`（場景與互動）、`src/island.css`（版面）。
- 驗證：92 項既有邏輯測試與 TypeScript／正式建置通過；3D 視覺、光線、點選與 iPad 手勢尚未經實機瀏覽器驗證。Three.js 動態載入檔案約 136 KB gzip；建置仍會提示其原始壓縮大小超過 500 KB。

## 線上遊玩與自動部署

遊戲網址：https://weilitien.github.io/math-adventure/

推送到 `main` 後，GitHub Actions 會安裝依賴、執行全部測試、建置，再部署到 GitHub Pages。部署進度可在儲存庫的 Actions 頁面查看；測試或建置失敗時不會覆蓋線上版本。

`vite.config.ts` 將正式建置的資源路徑設為 `/math-adventure/`，本機開發仍使用 `/`。若更改儲存庫名稱或改用其他網址部署，需同步調整 `base`。線上進度儲存在各裝置的瀏覽器，本機開發站的紀錄不會自動轉移到線上站。
